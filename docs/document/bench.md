# LLM 基准测试

魔曰采用文言文仿真技术，将加密数据编码为具有自然语言特征的文本。本基准测试旨在评估不同语言模型对魔曰密文的识别能力、内容安全判定结果及文本分类表现。

## 测试内容

明文为三个随机 UUID 首尾拼接。
三组中纯密文(50)与夹杂密文(50)使用同一密文，密文使用魔曰 V3.5.5 随机加密生成，所有模型使用同一批样本。

每模型每项 10 次，每次为独立会话。
表头数字(0/50)为随机指数。
