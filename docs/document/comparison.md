# 技术演进和功能对比

魔曰项目并非一蹴而就，而是站在了众多前辈的肩膀上。以下是文本风格化与数据处理领域内极具代表性的几款历史工具，我们对其技术特性进行了客观梳理。

## 核心特性概览

| 工具名称          | 风格特征        | 加密机制          | 运行环境  | 开源状态    |
| :---------------- | :-------------- | :---------------- | :-------- | :---------- |
| **魔曰 (本项目)** | 🟢 仿文言文     | 🟢 独立密钥 (AES) | 🟢 离线   | 🟢 社区开源 |
| **与熊论道**      | 🟢 特殊熊语汉字 | ⚪ 编码替换       | ⚪ 服务端 | 🟡 逆向开源 |
| **兽音译者**      | 🟢 拟声字       | ⚪ 编码替换       | 🟢 离线   | 🟢 社区开源 |
| **新佛曰**        | 🟢 佛经生僻字   | 🟡 密钥追加 (AES) | ⚪ 服务端 | ⚪ 闭源私有 |
| **文本隐水印**    | 🟢 零宽字符     | ⚪ 不可见字符     | 🟢 离线   | 🟢 社区开源 |

> **名词解释：**
>
> - **风格特征**：输出结果最终展现给用户的视觉风格。
> - **加密机制**：指底层是否采用了包含密钥的现代密码学算法（而非简单的查表替换或固定密钥）。

::: tip 魔曰密文示例
铃曰：“达驿者，涧之鲤也。” 以益木为家者，庭当弗而事之。有轻梦、佳心、新琴之鸳。极岩之曲，事之花而现之琴也。以空，当奏旧家，非声取璃所想颇言。或振楼呈鸢，画灯于鹂，非想迸也，鲤能御木振动，而礼梦弥定。
:::

## 经典同类项目

### 与熊论道

::: tip 熊曰密文示例
熊曰：呋食性類啽家現出爾常肉嘿達嗷很
:::

与熊论道曾是受众最广的文本风格化工具之一，其独特的“熊语”极具辨识度，也是魔曰项目立项的重要灵感来源。

由于历史原因，该工具依赖服务端执行解密且未公开源码，这导致其在 2025 年上旬服务器因故下线后面临密文数据无法解密的风险。基于对互联网历史数据的保护，本项目逆向分析并开源了其算法，以确保其历史密文数据可被解密并归档。

::: warning 提示

经过本项目原创逆向分析，熊曰的加/解密算法已被还原，本项目已公开相应实现。

详情请见 [**使用提示**](/document/demo-usage.md#熊曰解密-与熊论道) 和 [**Issue #123**](https://github.com/SheepChef/Abracadabra/issues/123) 。

有关本项目中内置的熊曰解密函数，请见 [**JavaScript 部署**](/document/js-deploy.md#beardecode-熊曰解密函数) 。

:::

### 兽音译者

::: tip 兽音密文示例
~呜嗷嗷嗷嗷呜呜啊呜嗷呜嗷呜呜~嗷啊呜啊嗷啊呜嗷呜~呜~嗷~呜呜嗷嗷嗷嗷嗷嗷呜啊嗷呜啊呜嗷呜呜~嗷啊嗷啊嗷啊呜嗷嗷~~~
:::

兽音译者是一款极具创意且广受欢迎的编码工具，它将二进制数据转化为由四个拟声词组成的字符串。其设计初衷主要偏向于娱乐和趣味性表达。魔曰在设计时深度借鉴了其纯离线运行的优秀理念，并在此基础上补齐了严密的加密架构和自然语义体系。

### 佛曰系列 (新佛曰 / 旧佛曰)

::: tip 佛曰密文示例
佛曰：諸南隸僧南降南吽諸陀南摩隸南僧南缽南薩咤南心彌嚴迦聞婆吽願南眾南色南兜南眾南如婆如南
:::

旧佛曰是现存最古老的文字风格化工具之一，诞生于 2010 年左右，在此后的十余年里孕育了诸多衍生版本，堪称此类工具的开山鼻祖。

后续的“新佛曰”引入了 AES-256 加密，但为了简化用户操作，其密钥是固定的且直接附加在密文中，主要依靠佛经生僻字展现其视觉风格。新佛曰同样已于 2025 年上旬因故下线。

### 文本隐水印

[文本隐水印](https://github.com/guofei9987/text_blind_watermark/) 是由 guofei9987 开发的优秀开源项目。

它通过 UTF-8 的零宽字符（U+2060/U+FEFF），将任意数据表示为二进制并悄无声息地嵌入到正常文本内，达到了肉眼不可见的神奇效果。魔曰项目在早期构建相关体系时，曾参考过其零宽字符的精妙运用思路。
